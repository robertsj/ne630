# NE 630 - Nuclear Reactor Theory

This repository contains public course materials for NE 630 - Nuclear Reactor
Theory at Kansas State University. The notes, examples, notebooks, and slides
were developed by Jeremy Roberts.

The syllabus is no longer maintained in this root README. Administrative
artifacts now live under `administrivia/`:

- Canonical syllabus source: `administrivia/syllabus.md`
- CourseDog import artifact: `administrivia/generated/syllabus-coursedog.md`
- CourseDog WYSIWYG copy helper: `administrivia/generated/coursedog-copy.html`
- Detailed schedule template: `administrivia/schedule.md`
- K-State syllabus policy and workflow notes: `administrivia/README.md`

Course content is organized mainly in:

- `pages/` for lesson pages and homework-facing Markdown/HTML.
- `slides/` for lecture slide sources.
- `notebooks/` for computational examples and tutorials.
- `build/` for generated Canvas-oriented HTML tooling.

For Fall 2026 and later terms, CourseDog is treated as the official syllabus
repository, while this repo remains the plain-text reference source for course
artifacts deployed to students through CourseDog, Canvas, email, or handouts.
