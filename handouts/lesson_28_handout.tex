\textbf{Average by delayed-neutron yield.} Let $s_j$ be the delayed-yield
share of nuclide $j$. Normalize the shares over the precursors being averaged:
\[
 \boxed{\bar{t}_{1/2}=\frac{\sum_j s_j t_{1/2,j}}{\sum_j s_j},\qquad
 \bar{\lambda}=\frac{\ln2}{\bar{t}_{1/2}}.}
\]
This preserves the mean delay $\bar{t}_{1/2}/\ln2$.
For the ten listed nuclides, divide by $71.6$: $\bar{t}_{1/2}=11.66$ s
and $\bar{\lambda}=0.05946$ s$^{-1}$ \emph{for this subset}.
The remaining $28.4\%$ is needed for a full U-235 average.
\SourceLine{Averaging procedure: FNRP Eqs. (5.32)--(5.34).}

Each $C_i$ is an \textbf{effective delayed-neutron precursor concentration}:
a reservoir of expected future delayed neutrons.
Unlike Lesson 27's $C=f_nN_{\rm Br}$, a grouped $C_i$ alone does not
determine an individual nuclide's concentration.

\Sec{2}{Equations and initial conditions}

With $\beta=\sum_{i=1}^{G}\beta_i$,
\[
 \boxed{\begin{aligned}
 \frac{dn}{dt}&=\frac{\rho(t)-\beta}{\Lambda}n+
                 \sum_{i=1}^{G}\lambda_i C_i+S(t),\\
 \frac{dC_i}{dt}&=\frac{\beta_i}{\Lambda}n-\lambda_i C_i,
                       \qquad i=1,\ldots,G .
 \end{aligned}}
\]
For an initially critical, source-free equilibrium,
\[
 \rho(0^-)=0,\qquad n(0)=n_0,\qquad
 \boxed{C_i(0)=\frac{\beta_i n_0}{\lambda_i\Lambda}.}
\]
These equations have the matrix form
$\dot{\mathbf y}=\mathbf A(\rho)\mathbf y+\mathbf b$,
where $\mathbf y=[n,C_1,\ldots,C_G]^T$ and
$\mathbf b=[S,0,\ldots,0]^T$.
The $(G+1)\times(G+1)$ matrix ($7\times7$ for $G=6$) has
\[
 \begin{aligned}
 A_{00}&=(\rho-\beta)/\Lambda,& A_{0i}&=\lambda_i,\\
 A_{i0}&=\beta_i/\Lambda,& A_{ii}&=-\lambda_i
 \end{aligned}
\]
for $i=1,\ldots,G$, and all other entries zero.

\textbf{Check.} With U-235, $n_0=10^8$ cm$^{-3}$, and
$\Lambda=5\times10^{-5}$ s, calculate $C_1(0)$.
Why is setting all $C_i(0)=0$ a different physical experiment?
\[
 C_1(0)=\RevealMath[1.4in]{3.393\times10^{10}}\ {\rm cm}^{-3}.
\]


\Sec{3}{The pathway to the inhour equation}

After a step insertion, take $\rho$ constant and $S=0$.
The coefficients are constant; try one exponential mode:
\[
 n(t)=a e^{\omega t},\qquad C_i(t)=b_i e^{\omega t} \, .
\]
Substitute $n(t)$ and $C_i(t)$ into the precursor equations,
and eliminate $b_i$:
\[
 (\omega+\lambda_i)b_i=\frac{\beta_i}{\Lambda}a
 \quad\Longrightarrow\quad
 b_i=\frac{\beta_i a}{\Lambda(\omega+\lambda_i)}.
\]
Substitution into the neutron equation gives
\[
 \Lambda\omega=\rho-\beta+
                  \sum_{i=1}^{G}\frac{\beta_i\lambda_i}{\omega+\lambda_i}.
\]
Use $\beta=\sum_i\beta_i$ and rearrange to obtain
\[
 \boxed{\rho=\Lambda\omega+
          \sum_{i=1}^{G}\frac{\beta_i\omega}{\omega+\lambda_i}.}
\]
This is the \textbf{inhour equation}. It is rational; clearing the
denominators gives the degree-$(G+1)$ characteristic polynomial.
For positive $\beta_i$ and distinct $\lambda_i$, as here, the poles
$-\lambda_i$ are not roots.

The full solution is a sum of $G+1$ modes (seven for six groups), with
amplitudes fixed by the initial state. The largest eigenvalue
$\omega_\star$ determines the late-time signed \emph{stable period},
$T=1/\omega_\star$:
\[
 \boxed{\rho=\frac{\Lambda}{T}
            +\sum_{i=1}^{G}\frac{\beta_i}{1+\lambda_iT}.}
\]
At criticality, $\omega_\star=0$ and the equilibrium period is infinite.
For a negative insertion, $T<0$.

\Sec{4}{One effective group and useful limits}

\textbf{Near criticality}, if $|\omega_\star|\ll\lambda_i$ for every group,
\[
 T\simeq\frac{\Lambda+\sum_i\beta_i/\lambda_i}{\rho}.
\]
A one-group model using Section 1's average preserves the equilibrium
total precursor inventory:
\[
 \beta_{\rm 1g}=\beta,\qquad
 \lambda_{\rm 1g}=\bar\lambda=\frac{\beta}{\sum_i\beta_i/\lambda_i}.
\]
For the U-235 groups on page 1, $\bar t_{1/2}=9.044$ s and
$\bar\lambda=0.076641$ s$^{-1}$. This reproduces the small-reactivity
limit. A mixture still has several modes; one effective group cannot
reproduce every transient. This is distinct from L27's Br-87-only model.

\textbf{Well above prompt criticality},
\[
 T\simeq\frac{\Lambda}{\rho-\beta}.
\]
This estimate requires the delayed term to be small relative to
$\rho-\beta$; the full period is finite at $\rho=\beta$.

\textbf{For a sufficiently large negative insertion},
\[
 \omega_\star\longrightarrow-\lambda_1,\qquad
 T\longrightarrow-\frac{1}{\lambda_1}=-80.79\ {\rm s}.
\]
Earlier decay can be much faster than this late-time limit.

\Sec{5}{Work with \texttt{ne630\_kinetics}}

Save \texttt{ne630\_kinetics.py} beside your notebook or script.
Its two functions are below. \texttt{f} is the right side of
Section 2's equations for $\mathbf y=[n,C_1,\ldots,C_G]^T$, with
$S=0$ and no feedback. \texttt{solve} starts from critical
equilibrium and passes \texttt{f} to SciPy's \texttt{solve\_ivp}.

\begin{lstlisting}[style=NEpython]
import numpy as np
from scipy.integrate import solve_ivp

def f(t, y, rho, betas, lambdas, Lambda):
    n = y[0]           # Unpack the unknowns so that
    C = y[1:]          #   the equations are clearer.
    beta = sum(betas)  # Total delayed neutron fraction
    dndt = ((rho(t)-beta)/Lambda)*n + sum(C*lambdas)
    dCdt = -C*lambdas + betas*n/Lambda
    dydt = np.zeros(len(y))
    dydt[0] = dndt     # Collect the derivatives
    dydt[1:] = dCdt    #   into one array that we return
    return dydt


def solve(rho, times, n0, betas, lambdas, Lambda):
    """Return n(t) and C_i(t), starting critical at n0.

    rho is a function of t, and C[i] is group i+1.
    """
    y0 = np.zeros(len(betas) + 1)
    y0[0] = n0
    y0[1:] = betas * n0 / (lambdas * Lambda)
    # Limit the step to the spacing of times so that the
    # solver cannot step right over a change in rho.
    hmax = np.max(np.diff(times))
    sol = solve_ivp(f, (times[0], times[-1]), y0,
                    args=(rho, betas, lambdas, Lambda),
                    t_eval=times, max_step=hmax,
                    method="LSODA", rtol=1e-8)
    return sol.y[0], sol.y[1:]
\end{lstlisting}

\columnbreak

\texttt{solve} returns \texttt{n} at each time in \texttt{times} and
\texttt{C}, where \texttt{C[i]} is $C_{i+1}$; with $n_0=1$, these are
$n/n_0$ and $C_i/n_0$. The argument \texttt{rho} is a Python function
of $t$ (s) that returns the dimensionless reactivity, so $d$ dollars
is $\rho=d\beta$. Enter the U-235 data from page~1.
For one group, pass $[\beta]$ and Section 4's $[\bar\lambda]$;
\texttt{solve} builds that model's own critical precursor inventory.

\begin{lstlisting}[style=NEpython]
import numpy as np
from ne630_kinetics import solve

betas = np.array([0.00021, 0.00142, 0.00128,
                  0.00257, 0.00075, 0.00027])
thalfs = np.array([56, 23, 6.2, 2.3, 0.61, 0.23])  # s
lambdas = np.log(2)/thalfs
Lambda = 5e-5                       # s
beta = sum(betas)
d = 0.2                             # dollars

def rho(t):
    return d*beta                   # step at t = 0

times = np.linspace(0, 200, 2001)   # s
n6, C6 = solve(rho, times, 1.0, betas, lambdas, Lambda)
b1, l1 = np.array([beta]), np.array([0.076641])
n1, C1 = solve(rho, times, 1.0, b1, l1, Lambda)
\end{lstlisting}

Once the faster modes have decayed, $\ln n$ is a straight line with
slope $1/T$, so $T\simeq(t_2-t_1)/\ln[n(t_2)/n(t_1)]$ for two late times.
Because \texttt{hmax} is the spacing of \texttt{times}, choose
\texttt{times} finely enough to catch every change in $\rho$.
From a terminal, \mbox{\texttt{python ne630\_kinetics.py}} plots
Lesson 27's Example 4.
