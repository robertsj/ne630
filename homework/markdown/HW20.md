## Problem 1

Suppose a sodium-cooled fast reactor is modeled in OpenMC and has
$k_{\mathrm{eff}}=1.00234$. Compute the reactivity, $\rho$, and express it in
each of the following units:

- **(a)** $\Delta k/k$,
- **(b)** percent,
- **(c)** pcm,
- **(d)** dollars, assuming all fission is from ${}^{235}\mathrm{U}$, and
- **(e)** dollars, assuming all fission is from ${}^{239}\mathrm{Pu}$.

If you did not record the needed delayed-neutron fractions in class, use
appropriate $\beta$ values from FNRP Table 5.1.

## Problem 2

Consider again the PWR described in FNRP Problem 4.6, which was studied in
Homework 17. Walk through the basic steps that bring the reactor from cold
shutdown conditions to criticality at full-power conditions using the modified
four-factor formula, similar to FNRP Eq. (10.3):

$$
k_{\infty}
=\overbrace{
  \frac{\nu\Sigma^{\mathrm{F}}_{f,2}}
  {\Sigma^{\mathrm{F}}_{a,2}
   +\Sigma^{\mathrm{control}}_{a,2}
   +\varsigma(V_{\mathrm{M}}/V_{\mathrm{F}})\Sigma^{\mathrm{M}}_{a,2}}
}^{\eta f}p\epsilon.
$$

The subscript 2 indicates the thermal group ($E<1~\mathrm{eV}$), while the
superscripts $\mathrm{F}$, $\mathrm{M}$, and $\mathrm{control}$ indicate fuel,
moderator, and control-rod values. Where needed, use the cross sections in FNRP
Table 3.2.

Using a programming language or spreadsheet to support your work is strongly
recommended. Show the basic steps and enough intermediate results for a reader
to follow the process. Keep your work organized because you will build on this
solution in a future homework.

- **(a)** Compute the four factors for $T_f=T_m=300~\mathrm{K}$ (room
  temperature). Assume that the nonleakage probability is
  $P_{\mathrm{NL}}=0.95$ and compute $\rho$. This reactivity is the **excess
  reactivity**, $\rho_{\mathrm{ex}}$: the core reactivity with all removable
  control, such as control rods and
  [chemical shim](https://www.nuclear-power.com/glossary/boron-10/boric-acid-chemical-shim/),
  completely removed.
- **(b)** Suppose the **shutdown margin** is
  $\rho_{\mathrm{sd}}=-4\%~\Delta k/k$; that is, with all control rods fully
  inserted, the core reactivity is $-0.04$. The total **reactivity worth** of
  the control rods is

  $$
  \Delta\rho=\rho_{\mathrm{ex}}-\rho_{\mathrm{sd}}
  =\rho_{\mathrm{ex}}+0.04.
  $$

  What must $\Sigma^{\mathrm{control}}_{a,2}$ be in this **cold shutdown**
  state? The NRC definition of shutdown margin excludes the control assembly
  with the highest reactivity worth; this simplified model cannot make that
  distinction.
- **(c)** Represent partial control-rod insertion by a fraction $x$, so the
  corresponding macroscopic cross section is
  $x\Sigma^{\mathrm{control}}_{a,2}$. As $x$ ranges from 0 to 1, the core
  reactivity should range from $\rho_{\mathrm{ex}}$ to $-0.04$. Determine the
  value of $x$ that makes the reactor critical. Call this value
  $x_{\mathrm{cc}}$, where “cc” denotes cold critical.
- **(d)** Next, run the reactor coolant pumps until the coolant and fuel reach
  $600~\mathrm{K}$, corresponding to **hot zero-power** conditions. Assume the
  coolant density is $0.66~\mathrm{g\,cm^{-3}}$. Recompute $\rho$ using
  $x=x_{\mathrm{cc}}$; this reactivity is the **temperature defect**. Then find
  the control-rod fraction that makes the reactor critical and call it
  $x_{\mathrm{hzp}}$.
- **(e)** Finally, bring the reactor to **full-power** conditions so the fuel
  temperature increases to $1200~\mathrm{K}$. Recompute $\rho$ using
  $x=x_{\mathrm{hzp}}$; this reactivity is the **power defect**. Determine the
  corresponding critical control-rod fraction, $x_{\mathrm{fp}}$.
