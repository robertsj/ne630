Shared LaTeX support¶

All source bundles include the shared ne630boardhandout.cls class. No course-specific .sty file is currently required. Compile a downloaded bundle with:

latexmk -xelatex -interaction=nonstopmode -halt-on-error lesson_01_handout.tex

The public body files are student-safe exports. Instructor reveal values and instructor-only figure content are deliberately omitted.
