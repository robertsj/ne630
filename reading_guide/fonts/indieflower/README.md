Indie Flower, Regular

Source: https://github.com/google/fonts/tree/main/ofl/indieflower
Original file: IndieFlower-Regular.ttf
License: SIL Open Font License 1.1; see OFL.txt.

The original static font is bundled unmodified and loaded by file path.
The regular design is used for all text shapes, with a light synthetic weight
(`FakeBold=1.0`) applied at typesetting time to balance Euler Math. No artificial
slant is applied, and the bundled font file remains unmodified.
Run `make indie-euler` for landscape trials with Indie Flower answer text and
Euler Math answer equations. Euler Math is supplied by the local TeX installation.
